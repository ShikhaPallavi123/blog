What is supervised learning?

Supervised ML trains an algorithm on a labeled dataset. Each input comes with the correct output, so the computer can learn patterns and then predict the output for new data.

Think of a teacher marking homework. The student sees the right answers while practicing, then faces a new test alone.

Linear Regression

We have 5 students: hours studied (x) and exam score out of 100 (y). The goal is to draw the best fit line through the dots and use it to predict a new score.

y = m·x + c

m is the slope, also called the coefficient. It says how many extra marks each study hour adds.

the c part

c is the intercept, also called the bias. It is where the line starts when x is 0.

The pink lines are the errors, the gap between each real score and the line. "Best fit" means the smallest total error (MSE, the mean of the squared gaps). Training finds m and c for you, and the result is the regressor, which is the hypothesis from Part 1.

Scikit-learn

sklearn is an open-source ML library for supervised and unsupervised learning.

Why people love it

① Well documented
② Easy to learn
③ Works well with NumPy and pandas
④ Used by professionals

Same example in code 
import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[1],[2],[3],[4],[5]]) # hours
y = np.array([50,55,65,75,90])      # score

model = LinearRegression().fit(X, y)
model.coef_       # [10.]  slope m
model.intercept_  # 37.0   intercept c
model.predict([[2.5]]) # [62.]

The numbers match the slider board above: m = 10, c = 37, and 2.5 hours predicts 62. To hold back test data, use train_test_split(X, y, test_size=0.2).
