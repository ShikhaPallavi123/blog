What is ML?

Machine Learning is a part of computer science where we teach computers to learn from data, find patterns, and make decisions or predictions.

Nobody types out every rule. The computer looks at lots of examples and works the rules out itself.

Normal code vs ML

In normal programming, you write the logic. In ML, the computer finds the logic. Watch the little dots travel through each one.

Normal programming input
logic (you write it)

Machine learning input + output examples
the computer
logic (a hypothesis) now try it on new data: new input

That learned logic is called a hypothesis. It is the computer's best guess about how inputs turn into outputs.

Example: spam emails

How does your inbox know what is spam?

The old way

A person looks at spam emails, spots patterns, and writes rules.

# patterns a human noticed
if sender.startswith("noreply@"):
    spam = True
elif sender.startswith("promo@"):
    spam = True
# ...and a hundred more if-else

Spammers change tricks, so you rewrite the rules forever.

The ML way

Show an ML algorithm thousands of emails that are already marked spam or not spam. It finds the patterns on its own.

Spammers change tricks? Feed it new emails and it learns again.

The 3 types of ML

1

Supervised Learning

Learn from labelled data. Every example comes with the right answer (input → output).

2

Unsupervised Learning

Learn from unlabelled data. Nobody gives answers, so the computer finds groups by itself.

3

Reinforcement Learning

Learn by trying things. Good moves get rewards, bad moves get penalties.

type 1

Supervised Learning

You give the computer labelled data: an input and its correct output. It splits into two jobs.

① Classification

Pick a class or category.

  • spam / not spam
  • cat / dog / rabbit
  • grade (A, B, C…)
② Regression

Predict a continuous value, a number that can be anything on a scale.

  • age
  • stock price
  • marks / score

Quick test: is the answer a label, or a number? Label means classification. Number means regression.

type 2

Unsupervised Learning

Here the data has no labels. The computer looks for natural groups. This is called clustering.

Picture a shop's sales: iPhones and chargers. Nobody says which is which, but the computer notices that some items sit together and splits them into two groups.

Dots start mixed up, then settle into groups. That is the computer finding patterns without answers.

type 3

Reinforcement Learning

This one is goal-oriented. An agent tries moves, gets rewards for good ones and penalties for bad ones, and slowly learns the best path to its goal. Think of training a puppy with treats.
