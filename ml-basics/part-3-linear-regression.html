Linear Regression
Under the Hood

By Shikha Pallavi

Part 2 showed what a best-fit line is. Now we ask how the computer finds it. The answer: measure the mistakes, add them up, and keep nudging the line until the total is as small as it can be.

Which line is the best fit?

Many lines can go through the same dots. Some are clearly wrong, and one sits closest to all of them. Try each line and watch the total error.

The best fit line gives the predicted values. Everything else is a worse guess.

Measuring the error

For every dot, the actual value is where the dot really is. The predicted value is where the line says it should be. The gap between them is the error, also called the residual error.

error = actual val − pred val
Try it on three points: (1, 1), (2, 2), (3, 3)
xactualpredictederror

Our goal is to minimize the error. When the line is y = x, every error is 0 and the fit is perfect.

The hypothesis function

More than one feature

Real problems have many inputs. Predicting a house price needs size, bedrooms, age and more. Each new feature gets its own coefficient. Add features and watch the formula grow.

The cost function

It measures how well the model's predictions match the actual data. One number for the whole dataset: small is good, big is bad.

First idea: add up the error of every point. But there is a catch. Errors can be plus or minus, and they cancel each other out. Pick a way to add up these four errors:

The most popular choice is squared error, which gives the Mean Squared Error (MSE). Squaring removes the minus signs, and it punishes big misses much harder than small ones. Other choices exist too, like log of error and absolute error.

J(θ) = 1⁄2m  Σi=1m ( hθ(x(i)) − y(i) )²
Reading it

m is the number of data points. For each point i, take prediction minus actual, square it, add them all, then divide by 2m.

Why the extra 2?

It is only there to make later math tidy. It does not change which line is best.

Learning = shrinking J

Here is the loop on the last slide. Start with any values for θ₀ and θ₁, compute J(θ), update θ₀ and θ₁ so J gets smaller, then repeat. This update method is called gradient descent.

To keep it visual we use the points (1,1), (2,2), (3,3) and fix θ₀ = 0, so only θ₁ changes. The curve is J for every possible θ₁. The best θ₁ sits at the bottom.

Try a big step size, like 0.45 to 0.5. The ball overshoots the bottom and the cost grows. Too small is safe but slow. That is why step size is a setting you choose.

Recap

Best fitThe line with the smallest total error.
Erroractual − predicted, also called the residual.
Hypothesish(x) = θ₀ + θ₁x₁ + … + θₙxₙ. One feature is a line, two a plane, more a hyperplane.
Cost J(θ)Mean squared error: (1/2m) Σ (prediction − actual)².
LearningUpdate θ again and again until J stops shrinking.
